# Data status

This archive uses the revised CD 403 dataset of 502 establishments. Old 329/503-record datasets are excluded.

raw_data contains the original Census workbook and the downloaded PLUTO area-query extract actually used for the population and land-use figures. These are not citywide full exports.

MISSING HISTORICAL RAW SNAPSHOTS: dohmh_queens.json, cscl_box.geojson, subway_entrances.json, facdb_cd403.json and the original boundary downloads were not included in the supplied chapter-2 ZIP and were not found in this workspace. The restaurant source was downloaded 3 November 2026, with latest record_date 30 October 2026. These historical raw files have NOT been replaced with new downloads. code/01_download.py preserves the original queries; running it retrieves current data, which may differ.

analysis_outputs contains the authoritative 502 cleaned restaurants, all walking results, summaries, used entrances, eligible streets, reaches and processed boundaries. The entry/road/school/boundary GeoJSON files here are processed inputs/outputs, not untouched download originals.

images contains only the four retained analysis figures: population, cuisine, retail/housing/schools and walking-time-by-corridor. Field photos and personal video are not included because no local source files are in this analysis workspace. Page preview screenshots, old figures, unused public-space layers and credential/upload scripts are excluded. AI attribution was added to StoryMap captions, not baked into the PNG files.

map_definitions contains the two supplied chapter-2 ArcGIS Web Map JSON files with embedded features. First-chapter native ArcGIS maps were configured through Map Viewer, not generated by a separate Python upload script; their input GeoJSON is included.
